# TianshangPulse 硬件设计

> 所有元器件须满足 AGENTS.md §4 约束：嘉立创可采购或淘宝常用现货。

## 1. 核心芯片

| 器件 | 型号 | 说明 |
|------|------|------|
| SoC | ESP32-P4NRW16 / NRW32 | 400MHz 双核 RISC-V，16MB PSRAM |
| PPG | MAX30102 | I2C，心率/血氧 |
| IMU | MPU6886 | I2C，加速度+陀螺仪 |
| 屏幕 | （待选型） | SPI 接口 LCD/AMOLED |

## 2. 接口分配

| 外设 | 接口 | GPIO |
|------|------|------|
| MAX30102 | I2C0 | SDA=18, SCL=8 |
| MPU6886 | I2C0 | 与 MAX30102 共享总线 |
| 屏幕 | SPI | 待定 |
| 电池管理 | — | 待定 |

## 3. 设计要点

- PSRAM 高速信号：阻抗控制、等长走线
- 传感器使用 I2C 接口（减少 GPIO 占用）
- 低功耗：LP 核（40MHz）负责看门狗与中断唤醒，HP 核（400MHz）仅推理时全速运行
